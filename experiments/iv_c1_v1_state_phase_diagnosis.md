# IV-C1 v1: native state sampling phase

The completed v1 run at `5920b73` is **valid but does not pass IV-C1**. Its calibration chose phase 0: maximum conductance error 4.23e-18 uS versus 7.76e-5 uS for a one-step shift. Across all 12 new-schedule × voltage confirmation cells, maximum conductance error was 1.53e-17 uS, current error 1.48e-15 nA and charge error 1.39e-14 nA ms. The voltage clamp and all negative controls passed.

Nevertheless every cell failed the preregistered state gate: maximum A/B state error was 0.7537896848, exactly the normalized 0.5 nS AMPA event jump. The initial interpretation was that native state sampling was left-continuous at the event time while the closed form was right-continuous. This was a **hypothesis**, not an established mechanism: equal A/B jumps can leave conductance B−A and current unchanged even when state sampling differs. The prospective v2 test falsified the proposed simple global convention; the native event/recording order requires a per-event forensic trace. The v1 failure remains unchanged.

The prospective v2 contract `experiments/iv_c1_deterministic_synapse_v2.json` makes state observables left-continuous exactly at event times, keeps all thresholds and canonical mechanisms fixed, and uses new calibration and confirmation schedules. It was tested independently and failed the state gate; see `experiments/iv_c1_v2_result.md`. The v1 archive and report are in `experiments/results/iv_c1_kaggle_5920b73/`.
